# Ember

A free time tracker for Mac. Ember notes the app or website in front of you, lets you fill in the time you spent away from the screen, and shows your month's workload as one number. Everything stays on your Mac: no account, no cloud.

Requires macOS 14 or later. Runs on Apple silicon and Intel.

## Install

1. Download `Ember-0.1.dmg` from [Releases](https://github.com/ragneselis/ember/releases/latest).
2. Open it and drag Ember onto the Applications folder.
3. Open Ember from Applications.

## The first time: Open Anyway

Ember isn't notarised by Apple yet, so macOS stops it the first time with a message that it can't check the app.

1. Click Done (or Cancel) in that message.
2. Open System Settings, then Privacy & Security.
3. Scroll down to the line about Ember and click Open Anyway.
4. Confirm with your password or Touch ID, then click Open.

You only do this once.

When Ember asks to see your browsers, allow it, so it can sort web time by site.
